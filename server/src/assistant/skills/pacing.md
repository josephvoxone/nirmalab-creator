# Skill: pacing

How long a film runs and how often it turns. The bands below were measured on four episodes of one
Indonesian serial (Nadia Omara, KHW): 24,812 / 5,604 / 5,247 / 5,602 words, 31–161 minutes. Use them
when the user asks why a reference video holds attention, or when a project feels slow.

## The four numbers that reproduced

| measure | band | how to apply here |
|---|---|---|
| words per spoken sentence | 9–12 | one narration line per shot, ≤ 12 words — the same limit the copy skill already sets |
| a turn word (tapi / nah / jadi / padahal) | every 15–22 s | a shot is 6–8 s, so a turn lands every 2–3 shots; a scene with six shots and no turn is too flat |
| direct address (kalian / kamu) | every 1.5–2.5 min | a 2-minute film: once, at the end. An 8-minute film: 3–4 times, never twice in one scene |
| spoken pace | 154–172 wpm | with TTS aim for ~160 wpm; at 160 wpm a 12-word line runs 4.5 s, which is one shot |

## What not to quote

- **Questions per hour** varied 56–131 across the four episodes. It describes an episode, not a format.
- **`[musik]` cue counts** varied 0–60 because transcripts only mark music where nobody is speaking.
  Use them to place score inside one long piece, never to compare videos.

Report a band as a band. If the user asks for a rule and the measurement only supports a range, give
the range and say so.

## Structure against runtime

- 60–90 s: hook → setup → turn → payoff, 10–16 shots, one direct address.
- 3–5 min: two turns (the second is the reveal), one address per minute at most.
- 30 min and up: this is a serial episode, not a film. The first minutes are for the returning
  viewer (thanks, recap, the episode number), the story starts after that, and the last 90 s points
  at the next episode.
- A long special is an *occasion*, not a longer version of a normal episode. Only go past 30 minutes
  if the project itself is the occasion, and say the extra cost out loud: more shots, more credits.

## Checking a cut before rendering

1. Every scene has a turn. If a scene has none, say which scene and what the turn could be.
2. Count narration words per shot; anything over 12 words gets split or cut.
3. Count direct addresses; two in a row means one is decoration.
4. If the user is modelling a reference video, ask for its link first — do not guess its pacing.
